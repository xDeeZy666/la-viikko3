Commands I used

  • date '+%Y-%m-%d %H:%M:%S %Z' – shows the current date, time and time zone
  • uptime -p – shows how long the server has been running since the last boot
  • df / --output=pcent | tail -n 1 – shows disk usage of the root filesystem, and the pipe passes the output to tail -n 1, which keeps only the last line
  • free -m | awk '/^Mem:/ {print $2, $7}' – shows memory usage in megabytes, and awk picks the total and available RAM from the Mem: line

How it works

status.sh is a Bash script that collects the server information with Linux commands and stores the results in variables and writes an HTML report.

The function disk_status takes the root filesystem usage percentage as input and uses an if statement to compare it to 80.

Cron runs the script once per minute. It's enabled at boot, so the report keeps updating after reboot.

Test results

  • Disk status with 50%: OK
  • Disk status with 80%: WARNING, otherwise OK
  • Disk status with 90%: WARNING
  • Automatic updates: the generation time changed from 11:32 to 11:34 without running the script manually
  • Reboot test: after reboot the site opened normally and uptime showed 'up 1 minute'.

What I learned

how to combine commands with pipes. E.g free -m | awk picks only the needed values from the output, so the script can store just the numbers in variables instead of the whole table
